## 无付费回归要求

以下项目约束实现行为，不自动产生模型收益结论：

- NEXT 关闭时不注入指导、不追加自动工作；保存设置不发送消息、不切换模型。
- 官方账号与 API 的模型策略同步，费用仍按真实路由统计。
- 检查候选扫描与明确登记分离；脚本、锁文件变化使登记失效。
- 权限拒绝、取消、超时、并发修改和产物过期不产生虚假通过。
- 原有 JSON 检查兼容；CSV、JSON、Markdown 使用固定文件验证结构与来源对应。
- 流式用量不重复结算；缺失价格或用量保留未知状态。
- 投影、设置持久化和重启恢复通过真实宿主另行检查。

## 真实前端对照协议

预定任务为 React + Vite 个人任务看板：任务增删改、状态与优先级、搜索筛选、本地持久化、输入校验、空状态和移动布局。

两组从相同空白模板开始，模型、思考强度、提示、依赖、工具权限与停止条件一致，唯一实验变量为 NEXT 开关。两组不能访问或复制对方代码。记录供应方实际返回的模型标识，不把滚动调用别名当作固定权重版本。

首次交付后独立构建和浏览器交互检查，保留桌面及手机截图；外部人员不补代码后再给首次交付评分。评分隐藏开关身份，固定为：功能与完整性 60 分、视觉 20 分、可用性与无障碍 10 分、可维护性 10 分。启动失败、数据丢失和核心功能缺失单列；修复另计返工。

同时记录墙钟耗时、请求数、Token、估算费用、验收失败项与返工。允许“各有优劣”或“未观察到优势”，不推广为全场景结论。

## 付费与隐私边界

仓库不提供用户凭据、私人 profile、会话或费用账本。评测脚本不是一键免费测试：使用前必须有明确授权、核实后的有效价格、可审计预算和完整预留账本。新用户缺少账本或环境时，应先完成隔离配置与无付费预检，不要盲目运行付费入口。

每次请求派发前预留费用，重试与辅助调用一并计入。出现无法确认用量或费用的请求时保留预留并暂停后续付费调用，不能将未知金额清零来继续评测。
